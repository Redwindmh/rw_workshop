## Symptom

The access-point connection failed during activation with an authentication-related timeout.

## Lesson

Error text describes where a process stopped, not necessarily the root cause. The useful path was to inspect the generated connection properties, verify the interface role, and reduce the configuration until the access point could be brought up deterministically.

Failures stay in the log because the diagnostic path is often more reusable than the final command.
