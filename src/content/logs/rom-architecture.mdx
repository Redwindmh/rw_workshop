## Problem

Loading a game is deceptively easy to implement in the wrong layer. A direct file-system call from emulator code works quickly, but makes every later storage change expensive.

## Decision

ROM discovery belongs to the application layer, storage access belongs behind a narrow interface, and the emulator core should receive data without knowing how it was found.
