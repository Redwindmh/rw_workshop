## Objective

Build a self-contained handheld emulator while treating the firmware as a real systems project rather than a single demonstration sketch.

## Architecture goals

The codebase is divided around responsibilities such as platform initialization, input, display, storage, ROM handling, and emulator integration. Features are added only when their ownership inside the architecture is clear.

## Current focus

The current development phase is centered on persistent state, storage layout, and making game loading independent from emulator internals.

## Later work

- improve boot and game-selection flow;
- formalize storage APIs;
- profile memory pressure;
- document hardware revisions alongside firmware revisions.
